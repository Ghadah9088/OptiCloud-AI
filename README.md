# OptiCloud AI Engine 🚀

A lightweight FinOps & Cloud Asset Governance tool designed to detect idle cloud resources, reduce attack surfaces, and optimize infrastructure spending across cloud providers.

## Key Features
- **Active Scanning & Metrics Inspection:** Cloud Provider API integration (GCP Compute SDK).
- **Automated Cost Optimization:** Identifies unattached disks and idle compute instances.
- **Interactive UI Dashboard:** Real-time visibility into active workloads and monthly potential savings.

## Tech Stack
- **Backend:** Python, Flask, Cloud SDKs
- **Frontend:** HTML5, CSS3, JavaScript
